# Fixed-source asynchronous imports

Refs #11. POST and GET `/internal/v2/problem-imports` use the published DTOs. A new accepted request returns202; identical request replay returns200 with the persisted current job even during readiness loss. Conflicting bodies return409. The repository serializes concurrent acceptance and updates each item, retained evidence and aggregate counts in one transaction.

Acquisition uses the reviewed OJ-Lab repository and exact commit from [the package protocol](../contracts/v0.2/package-protocol.md). Other syntactically valid revisions become retained unsupported items without fetching unreviewed sources. Git receives a fixed executable/argv, a private bare repository and an explicit environment. It never checks out packages or executes hooks, submodules, credential helpers or caller commands. Optional transport configuration comes only from the operator and permits no proxy credentials. Exact Git blob bytes and modes produce the independently frozen archive/manifest hashes. Extraction, adaptation and acquisition execute no imported program.

The pipeline durably stages original and normalized archives before registration. Automatic collection records license bytes and provenance as MISSING or REVIEW_REQUIRED. It cannot supply approval columns or create VERIFIED evidence. The [offline human review](license-review.md) appends approved evidence bound to the exact source; a new import can then run qualified technical checks. Rejected items retain private originals, derived bytes, adaptations and real failure evidence independently of a problem identity. Successful items register immutable artifacts, tests, references, selected qualification and unpublished versions; import does not change the catalog or publish.

Every program/case event is retained as ordered NDJSON in1MiB content-addressed chunks. The pipeline checks the complete stream count and SHA-256 against the coordinator, seals a private report/index, and attaches chunks and logs to immutable owner records. SQL registration reserves all object locks in stable key order before inserting owners. Long validation renews one-hour stage pins; rollback leaves bounded staging for reconciliation. Private bytes, object keys, validator/reference paths and tool logs stay outside ImportItem DTOs; public diagnostics use fixed messages.

The worker reserves an initial attempt plus at most three counted recoveries. Every reservation has a fresh fencing token and180second database lease. Heartbeats run every30seconds, acquire the row lock before checking the actual database deadline, and never change public revision/timestamps. Terminal items survive recovery. Ambiguous execution/journal failures stop the reservation; a fresh counted lease controls another attempt. Exhaustion rejects only pending items while preserving committed DRAFT versions and evidence.

Interrupted validation retains its observed event prefix and bounded original diagnostics in a separate immutable `import_attempt_evidence` audit under the still-live fence. The audit records `complete=false`, the reservation token/recovery count, its own observed-prefix hash/count and explicit log truncation when needed. It cannot complete the item, create a qualification or extend the lease. The worker stops heartbeats before the short audit transaction; stale or expired owners cannot append it. Original archives, partial report and event chunks have independent historical object ownership and survive garbage collection. A storage/database failure can prevent this final audit; it still stops the reservation and never permits unrestricted execution or an uncounted retry.

Portable and PostgreSQL checks are separate from Linux qualification:

```sh
make check
# Supply JUDGE_TEST_ADMIN_DSN_FILE privately for actual PostgreSQL integration.
GOTOOLCHAIN=local .local/toolchains/go1.26.8/go/bin/go test -mod=readonly -race -count=1 ./internal/imports ./internal/persistence/imports
# Explicitly enables acquisition of the fixed public source; no program runs.
JUDGE_TEST_ACQUIRE_PINNED=1 GOTOOLCHAIN=local .local/toolchains/go1.26.8/go/bin/go test -mod=readonly -race -count=1 ./internal/imports -run TestActualPinnedAcquisitionMatchesIndependentCorpus
```

The optional test-only `JUDGE_TEST_PINNED_GIT_DIR` borrows an existing exact-commit Git cache for an offline byte check; it does not qualify network acquisition. `JUDGE_TEST_SOURCE_PROXY` supplies an explicit credential-free transport for the acquisition test. On2026-10-08, actual PostgreSQL17.10 race tests verified rejection retention, private DTOs, whole-source failure, concurrent admissions, live-lock expiry, stale fences, rollback and four-reservation recovery. Both the offline cache check and fresh fixed-source network acquisition through the explicitly configured host proxy matched the independently frozen hello-world archives. The host's direct GitHub connection failed and was not counted as passing acquisition evidence. These tests do not establish real technical validation, human rights coverage or sandbox qualification. The production default refuses imports until both measured helpers are available.
